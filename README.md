# Praktika-Mor-4-09PS-2
Основные функции
Управление задачами
Создание задач — добавление новых задач с указанием названия, описания, проекта, исполнителя, приоритета, дедлайна и тегов
Просмотр задач — отображение списка задач с возможностью фильтрации
Статус задач — отслеживание выполнения (в работе / завершена)
Приоритеты — визуальное выделение задач по приоритету (высокий, средний, низкий)

Проекты
Список проектов — просмотр всех активных проектов
Прогресс проектов — отображение процента выполнения
Статистика — количество выполненных и общих задач в проекте
Детальная информация — просмотр подробной информации о проекте

Команда
Список сотрудников — информация о членах команды
Фильтрация по отделам — разработка, дизайн, менеджмент
Контакты — email и телефон сотрудников
Статус онлайн — индикатор присутствия
Поиск
Живой поиск — мгновенная фильтрация задач при вводе текста


Основные экраны
MainActivity — главный экран с задачами текущего пользователя
TasksActivity — полный список всех задач с фильтрацией
ProjectsActivity — список проектов с прогрессом
TeamActivity — список сотрудников с контактами
ProjectDetailActivity — детальная информация о проекте
NewTaskActivity — форма создания новой задачи

Функциональные возможности по экранам
Главный экран
Просмотр задач, назначенных на текущего пользователя
Отметка задач как выполненных
Быстрый переход к проектам, задачам и команде
Создание новых задач
Экспорт данных

Экран задач
Фильтрация по категориям (все, мои, активные, завершенные)
Детальный просмотр информации о задаче
Визуальное выделение приоритетов

Экран проектов
Фильтрация проектов (все, активные, завершенные, важные)
Отслеживание прогресса
Переход к детальной информации
Экран команды
Фильтрация по отделам
Контактная информация сотрудников

Статус онлайн

Запустите на эмуляторе или реальном устройстве
